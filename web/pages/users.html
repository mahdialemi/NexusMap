About NexusMap

NexusMap

Version 1.0 · Network Scanner & Asset Management

What it does

NexusMap is a network scanner management platform. It allows you to create projects, run Nmap scans, manage scan profiles, and consolidate results in one centralized dashboard. Built for security professionals who need to organize and track their network assessments efficiently.

How it was built

This project was built using Vibe Coding — an AI-assisted development approach where the entire codebase was generated through natural language conversation.

Powered by OpenCode CLI with the Big Pickle model.
